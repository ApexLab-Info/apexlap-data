# apexlap-data

Community data for the **ApexLap** app (shared circuits, public profiles and rankings).

- This repository is maintained automatically. Please do not edit the files by hand.
- Everything here is public. The app only sends what you explicitly confirm.
- To contribute, use the app (**Community** screen). Issues opened by hand may be closed without a reply.
- Found a problem or want something removed? Open an issue titled **Report** and describe it briefly.

ApexLap is provided as is, without any warranty.
